# React Hooks 정리

React Hooks는 함수형 컴포넌트에서 상태와 생명주기 기능을 사용할 수 있게 해줍니다.

## useState

```tsx
const [count, setCount] = useState(0);
```

## useEffect

```tsx
useEffect(() => {
  console.log("Component mounted");
  return () => console.log("Component unmounted");
}, []);
```
