## OpenGL
- 프로그램에서 만들어진 명령 -> OpenGL -> 그래픽스 하드웨어로 전달된다.
- 자동차 컨베이어 벨트처럼 OpenGL은 할당 받은 작업들을 병렬화할 수 있는 기본 단위로 분할한다.
- Application과 Graphics SubSystem의 추상화 레이어를 제공한다.
- Application은 추상화 레이어를 통해 GPU 제작사가 어디인지, 어떻게 동작하는지, 성능이 어떤지 알 필요가 없다.

## 그래픽스 파이프라인
버텍스 패치 -> 버텍스 쉐이더 -> 테셀레이션 컨트롤 쉐이더 -> 테설레이션 -> 테셀레이션 이벨류에이션 쉐이더 -> 지오메트리 쉐얻 -> 래스터라이제이션 -> 프래그먼트 쉐이더 -> 프레임버퍼 동작

## 프리미티브, 파이프라인, 픽셀
- 프리미티브
    - OpenGL 렌더링의 기본 단위
    - 점, 선, 삼각형
- 버텍스
    - 좌표 공간상의 하나의 점
- 그래픽스 파이프라인은 프론트엔드와 백엔드 두 개의 파트로 분할된다
    - 프론트엔드 : 버텍스, 프리미티브를 처리하여 점, 선, 삼각형으로 구성하고 래스터라이저에 보낸다. (프리미티브 어셈블리)
    - 백엔드 : 지오메트리가 벡터 형태에서 대량의 각각 픽셀로 변환된다. 깊이 및 스텐실 테스트, 프래그먼트 쉐이딩, 블렌딩, 출력 이미지 갱신 등의 작업이 포함된다.
