# TypeScript 기초

TypeScript는 JavaScript에 정적 타입을 추가한 언어입니다.

## 기본 타입

```typescript
const name: string = "John";
const age: number = 30;
const isActive: boolean = true;
```

## 인터페이스

```typescript
interface User {
  id: number;
  name: string;
  email?: string;
}
```
