이제는 조금씩 비주얼과 아트를 신경 쓴다. 지형은 임시 리소스다. 유닛 픽셀아트는 직접 찍고 있다.

게임 개발에는 프로그래밍, 기획, 시나리오, 아트, 사운드 등등 여러 분야가 있다. 오늘은 프로그래밍 영역만 적어 본다.

코드는 AI에게 99% 맡긴다. 내가 하는 일은 AI가 잘 돌아갈 수 있는 환경을 세팅하는 것(하네스), 그리고 가끔 코드 검토뿐이다.

지금까지 여러 모델을 써 봤다. AI 모델이랑 요금제에 대한 생각을 간단히 적는다.

## Claude ($20, $100): Claude Code

요즘 요금 관련 논란이 많지만, 그래도 제일 무난한 것 같다. 주로 Opus급을 쓴다. Fable은 설계나 글을 쓸 때 많이 쓰는 것 같다. 알잘딱을 제일 잘해서 쓰면서 마음은 편하다. 다만 디버깅이나 버그 추적에서는 헛소리도 많이 해서, 답답할 때가 있다.

$20은 많이 부족하다. $100이면 취미 생활로는 충분한 것 같다.

지금은 Grok을 주력으로 써 보고 있어서, Claude는 Gemini가 쓴 시나리오를 검토하는 용도로 쓴다.

## GPT ($200): Codex

현재 AI 코딩에서는 Claude와 양대산맥인데, 장단점이 있다. GPT는 딱 시킨 것만 하는 경향이 있지만, 꼼꼼하게 본다고 느낀다. 돌다리 하나하나 두들겨 보고 건너가는 느낌이다. 프롬프팅을 섬세하게 잘하는 사람에게는 더 좋은 AI가 아닐까 한다.

$200일 때는 정말 미친 듯이 썼다. 병렬로 몇 개씩 동시에 돌려서, 주간 100%도 채워 본 적이 있다.

곧 Astra라는 모델이 나온다는 루머가 있다. 어떨지 기대된다.

## Gemini ($20): Antigravity

작년에 나를 AI 코딩의 세계로 인도해 준 Gemini인데, 솔직히 별로다.

코딩 말고 글 쓸 때 좋은 것 같다. 시나리오, 스토리 구상할 때 쓴다.

오늘 3.8 Flash가 나왔다. 요즘 Flash만 나오고 있어서 행보가 아쉽다.

## Grok ($100): Grok Build

Grok 4.6이 나와서 저번 달부터 써 보고 있다. 솔직히 Claude, GPT에 비하면 체급은 한 단계 낮다. 다만 내가 하는 작업이 어려운 수준은 아니라서, 의외로 또 쓸 만하다. 어느 정도 하네스 세팅이 필요하다고 생각한다.

Claude나 Codex와는 다르게 week usage만 있다. 그런데 $100은 많이 부족하다. Grok 4.6이 비용이 싸다고 약팔이를 하는데, Long Context에서는 사용량이 엄청나게 먹는다. 코딩이나 장기 작업에는 정말 별로다.

이번 달에는 Grok 구독을 끝낸 뒤에 Cursor로 넘어가 볼까 한다. 다양한 모델과 하네스를 쓰는 것도 좋은 경험인 것 같다.

주변에 AI 개발을 시작할 때는 Claude를 추천하는 편이다. 특히 비전공자에게. 알잘딱이 중요한 것 같다.

## 워크플로우

### 기획, 설계

작업 전에 설계부터 한다. 최대한 AI와 대화를 주고받으면서 컨텍스트를 쌓고 진행한다. brainstorming, grill-me 같은 소크라테스 문답법, 인터뷰 형식의 스킬을 쓰면 더 좋다. AI와 내 생각을 맞추는 작업이라고 생각한다. 이런 스킬들에서 영감을 받아서, 따로 나만의 스킬을 만들어 쓰고 있다.

여러 문서로 내 의도가 잘 전달됐는지 파악한다. Spec-Driven-Development를 참고해 보면 좋다.

다 된 것 같으면 바로 작업하지 않는다. 이슈부터 등록한다.

### 이슈 관리

Git과 GitHub는 당연히 쓴다. Git은 꼭 익혀 보길 추천한다.

GitHub의 Issue, Pull Request를 써서 일감이랑 마일스톤을 관리한다. 신규 기능 개발 건, 발견한 버그는 Issue로 등록한다. 작업 도중에 발견한 버그는 별도 이슈로 등록하고 나중에 처리한다.

PR을 올리기 전에 AI 코드리뷰를 돌린다. 지적 사항은 묶을 수 있는지에 따라 같이 넣거나, 별도 Issue로 등록한다. 코드리뷰 얘기는 나중에 적어 보려고 한다.

모든 Issue 등록은 AI가 한다. 내가 직접 쓰지 않는다. "해줘" 하면 다 해 준다. 가끔 설명을 부족하게 적을 수도 있는데, 관련 스킬이 이미 많이 있으니 설치해 주면 좋다.

새로운 작업은 Issue 번호 기준이다. "717 이슈 진행하자" 하면 알아서 코드를 읽고 컨텍스트를 잡는다.

주변에는 항상 GitHub Issue로 프로젝트 관리를 해 보라고 한다. 사실 꼭 GitHub Issue가 아니어도 된다. 중요한 건 일감, 이슈로서 관리되는지, AI가 거기에 접근 가능한지다. 혼자 메모장에 끄적이면 AI에게 전달하기 힘들고, 머리도 복잡해진다.
