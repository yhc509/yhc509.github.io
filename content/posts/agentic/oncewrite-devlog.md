바이브코딩으로 뭔가를 만들어서 팔아 보고 싶었다. 뭘 만들지는 모른다. 계획만 거창하게 세워 놓고, 아이디어를 찾고, 탈락시키고, 다시 찾는 과정을 한 세션 안에서 전부 겪었다. 결국 OnceWrite라는 콘텐츠 리퍼포징 도구가 프로덕션까지 갔다. 첫 커밋부터 배포까지 22시간.

## 워크플로우부터 설계했다

처음부터 "이걸 만들자"로 시작하지 않았다. 바이브코딩으로 웹 서비스를 만들고 파는 전체 파이프라인을 먼저 설계했다. 기술 스택 비교, 아이디어 발굴법, 마케팅 자동화, 수익 모델까지 꽤 상세하게 잡았다. 새 프로젝트를 시작할 때 복사해서 바로 쓸 수 있도록 CLAUDE.md, PRD, .env 템플릿도 만들었다.

여기까지는 순조로웠다. 문제는 그다음이다. 뭘 만들 건데?

## 옆길을 꽤 많이 돌았다

"외주도 자동화할 수 있지 않을까?" Upwork API를 조사하고, 실제 외주 건을 하나 골라서 연습해 보자는 방향이었다. Instagram DM 자동화 SaaS를 연습 과제로 잡았는데, 나는 인스타를 안 쓴다. 계정이 없다. 트위터로 대체하자니 API가 월 200달러. Mock 데이터로 하자니 AI가 한마디 했다.

> 연습 프로젝트를 만드는 것은 "코딩 연습"이지 "사업 연습"이 아닙니다.

접었다.

Product Hunt도 조사했다. AI 카테고리가 전체의 40~50%. 게임 개발 도구는 비주류. 게임 쪽 유일한 성공 사례인 Meshy도 "게임 도구"가 아니라 "AI 3D 모델 생성기"로 포지셔닝해서 먹힌 거였다. 내가 만든 Character Forge도 비슷한 구조지만 SaaS로 전환하기엔 시장이 포화.

게임 관련 아이디어도 여러 개 검토했다. 밸런스 시뮬레이터가 끌렸고 상세 계획까지 세웠는데, 솔직히 나도 아직 밸런스 조정을 본격적으로 해 본 적이 없다. AI도 감으로 하는 것 같았다. CLI로 돈을 어떻게 벌지도 모르겠고.

> 계속 리서치만 하면 영원히 시작을 못합니다.

맞다. 그냥 하나 골라서 2주 안에 만들고 출시하자.

## OnceWrite

"콘텐츠 리퍼포징 도구"를 골랐다. 블로그 글 하나를 넣으면 Twitter 스레드, LinkedIn 포스트, Reddit 글, 뉴스레터, 요약, 팁 리스트 6가지 버전으로 변환해 주는 서비스. 이름은 OnceWrite. 한 번 쓰면 여섯 번 쓰인다.

스택은 Next.js + Clerk(인증) + LemonSqueezy(결제) + Supabase(DB) + Claude API(변환). Stripe가 한국에서 안 되니까 LemonSqueezy로 대체했다. LemonSqueezy는 MoR이라서 전 세계 매출세/VAT까지 처리해 준다. 한국 1인 개발자에게는 이쪽이 현실적이다.

## MVP는 하루

Codex에 개발을 위임하고 나는 계정 세팅에 집중했다. Clerk, Supabase, LemonSqueezy, Anthropic API 계정을 만들고 키를 넘겼다.

순조롭지만은 않았다. Clerk 가입 시 CAPTCHA 에러(Bot Protection 끄면 해결), API 크레딧 부족(5달러 충전), 레포 이름 오타(OnceWrtie). 그래도 빌드는 통과했고, 내 블로그 글을 넣어 봤다. 변환 한 번에 0.02달러. 영어 번역은 잘 됐는데 한국어에서 JSON 파싱이 깨졌다. Haiku가 한국어 출력할 때 JSON 형식을 깨뜨린 것. 고쳤다.

## 배포 전에 크리티컬이 6건 나왔다

MVP가 돌아간다고 바로 배포할 수는 없었다. 보안, 로직, 법적 문서를 3단계로 점검했더니 크리티컬 6건이 나왔다.

인상적이었던 것 몇 가지. Google AI API 키가 URL 쿼리 파라미터로 노출되고 있었다. 프록시 로그에 평문으로 남는 구조. 헤더로 옮겼다. 준거법이 한국법인데 약관이 영문만 있었다. 전자상거래법 위반 소지. 개인정보보호법 필수 항목도 빠져 있었다.

SaaS 배포가 처음이라 보안과 법률을 공부하면서 갔다. Supabase에서 가장 흔한 사고가 RLS 미설정이라는 걸 이때 알았다. 2025년에 Lovable로 만든 170개 앱이 RLS 안 켜서 DB가 통째로 노출된 사건이 있었다고.

## 과금 모델을 갈아엎었다

처음에는 월 $9 Pro + 무료 3회였다.

> 어렵습니다. ChatGPT에 직접 하면 무료라는 전형적인 AI 래퍼 함정에 걸립니다.

AI가 솔직하게 말해줬고, 맞는 말이라 구조를 바꿨다. 유료 결제는 막아 두고, 무료 티어를 일간 크레딧으로 전환했다. 하루 10크레딧, 플랫폼 1개 변환당 1크레딧 차감. 로그인해야 충전된다. 매일 돌아올 이유를 만들기 위해서다.

기존 모델은 6개 플랫폼을 한 번에 선택해도 1회로 카운트되어서 밸런스가 안 맞았다. 건당 차감으로 바꾸니 직관적이 됐다.

## Gemini를 1차로 세웠더니

비용을 줄이기 위해 Gemini Flash Lite를 1차 모델로, Claude Haiku를 fallback으로 설정했다. Gemini 무료 티어가 일 1,500 요청이라 초기에는 충분하다.

문제는 품질이었다. 한국어 글을 일본어로 변환하는데, 프로필 설정을 켜면 번역이 깨졌다. 시스템 프롬프트에 프로필 정보가 들어가면서 Gemini가 출력 언어 지시를 무시하고 입력 언어를 따라간 것이다. 이름 필드를 빼면 해결됐다.

작은 모델의 전형적인 한계다. 프롬프트가 길어지면 세부 지시를 놓치기 시작한다. 무료와 품질 사이의 트레이드오프는 앞으로도 계속될 것 같다.

## 22시간

첫 커밋부터 Vercel 프로덕션 배포까지 22시간.

아이디어 탐색에서 시작해서, 외주/PH/게임 도구를 거쳐 OnceWrite를 확정하고, 풀스택 구축, 보안 점검, 크레딧 시스템 전환, 법적 문서 이중 언어 작성, 모델 fallback, UI 폴리시, 배포까지 갔다. AI 코딩 도구 없이는 1~2주짜리 작업이다.

## 다음은?

배포는 했는데 사용자가 없다. 마케팅 인맥도 없고, 눈팅 전문가 체질이라 커뮤니티 활동도 익숙하지 않다.

남은 선택지는 빌드인퍼블릭이다. Reddit에 올리고, Twitter에 과정을 기록하고, Product Hunt에 런칭하는 순서. 익명 부계정이면 된다. 인디해커 커뮤니티에서 닉네임은 아무도 신경 안 쓴다. 만들고 있는 게 보이면 그걸로 충분하다.

봐야 할 지표는 하나다. 다시 돌아온 사람이 있는가. DAU가 몇이든 매일 크레딧을 소진하는 사람이 있으면 그게 유료 수요다.

여기까지가 22시간 동안 벌어진 일이다. 아이디어 없이 시작해서 프로덕션 배포까지는 갔다. 이제부터는 만드는 게 아니라 검증하는 단계다. 앞으로의 과정도 기록해 볼 생각이다.
