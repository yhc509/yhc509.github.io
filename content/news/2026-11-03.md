Cursor 마켓플레이스에 올라온 Claude Code 확장 2.1.312와 2.1.313은 Anthropic이 빌드하지 않은 변조본이었다. Cursor는 노출 구간을 10월 29일 18:27 KST부터 10월 30일 05:35 KST까지로 밝혔다. 영향은 최대 5000명이라고 했다.

- 공격자는 정상 2.1.312의 버전 번호를 재사용했다. 마켓플레이스에 올라온 2.1.312와 2.1.313은 Anthropic이 만들지 않은 파일이다. 같은 번호가 정상본과 변조본 양쪽에 붙어 있다. Cursor는 Windows와 macOS용 이 두 버전을 악성으로 적었다.
- Cursor는 Open VSX 직통 대신 marketplace.cursorapi.com을 쓴다. Socket은 2.1.313의 게시나 삭제 기록이 없다고 적었다. Ars와 The Register는 두 회사가 침입 경로에 답하지 않았다고 전했다.
- Phorion은 악성 코드가 확장 파일이 로드되자마자 IIFE로 실행된다고 적었다. 이 코드는 SSH 키를 추가한다. 리버스 터널을 연다. 지속 실행을 심는다. 환경 변수 이름을 수집한다. Expel이 조사한 Mac 4대에서는 호스트 이름, 사용자 이름, OS, 홈 디렉터리, 작업 디렉터리, Git 이메일, 공인 IP, 환경 변수 이름이 나갔다. 관리자가 아닌 사용자에서도 터널이 연결됐다. 공격자의 SSH 로그인 성공은 보이지 않았다. 확장 자동 업데이트는 로그인한 사용자의 권한으로 실행된다. Phorion은 백도어 확장이 IDE와 그 사용자의 권한을 그대로 받는다고 적었다.
- VS Code Marketplace, Open VSX, npm에는 이 변조본이 없었다. Anthropic 엔지니어 ddworken은 VS Code와 Open VSX 공식 채널이 영향받지 않았다고 적었다. Microsoft Threat Intelligence는 VS Code Marketplace와 npm이 영향받지 않았다고 확인했다.
- Expel은 Mac 4대를 조사했다. 노출 구간만 보면 감염 기기를 놓칠 수 있다고 적었다. 구간 뒤에 변조본을 더 제공한 증거는 보지 못했다.
- Cursor는 최신 공지의 점검 명령과 IOC 목록으로 확인하라고 적었다. `~/.ssh/authorized_keys`와 지속 실행 항목도 확인한다. 확장만 지우는 것으로는 부족하다. 정리 스크립트를 실행한다. 확장을 2.1.314 이상으로 올린다. 영향받은 자격 증명을 교체한다.
- Hacker News(1,007점, 댓글 553개)에서 많이 나온 주제는 서명, 자동 업데이트 지연, 게시 키가 누구 것인지였다. Cursor와 Anthropic은 실제 침입 건수를 밝히지 않았다.
