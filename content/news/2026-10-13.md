## xAI, The X Subscription 출시

```cards
logos:
  - grok
  - icon: bot
    label: Grok Bot
  - cursor
  - x
caption: 요금제 하나로
```

xAI가 Grok, Grok Bot, Cursor, X Premium을 요금제 하나로 묶었다. 단계는 Free, Plus, Premium, Super, Ultra 다섯 개로 나눴다. 유료 플랜에서는 Grok 앱과 Cursor가 Grok 모델 사용량을 같이 쓴다. 기존 SuperGrok, Cursor, X Premium 구독자는 지금 플랜을 계속 써도 된다. 결제 설정에 전환 버튼이 뜨면 옮길 수 있고, 그때 이전 플랜의 남은 기간을 환불받는다.

### 출처

[xAI 공식 발표, 10월 12일](https://x.ai/news/x-subscription)

### 내 생각

플랜 통합은 필요했다. 통합 전에는 플랜끼리 비교하기가 어려웠다. 예를 들어 Cursor Pro+와 SuperGrok 중 어느 쪽이 Grok Bot을 더 많이 쓸 수 있는지 아무도 명확히 답하지 못했다. Cursor는 Cursor 플랜끼리만, SuperGrok은 SuperGrok 플랜끼리만 비교해 줬기 때문이다. 같은 용도로 고를 수 있는 선택지가 두 개였는데, 설명이 모호해서 정답을 아는 사람이 없었다. 꽤 오랫동안 통합 루머가 돌다가 드디어 합쳐졌다. 플랜 변경 영향인지는 모르겠지만, 바꾸고 나서 Grok Bot 사용량에 여유가 생긴 느낌이다.

Cursor 가격표에서 Pro, Pro+가 빠지고 그 자리에 X Subscription 다섯 단계가 들어갔다. Plus는 Grok 모델만 쓸 수 있다. Super는 Premium에 두 가지를 더한다. Plus의 15배 사용량을 주고, 붐비는 시간대에는 먼저 처리해 준다. 다른 회사 모델은 Premium부터 쓸 수 있다. 대신 쓴 만큼 따로 낸다. Cursor 공식 X 계정은 유료 플랜이 같은 급 Cursor 플랜보다 Grok 모델 코딩 사용량을 두 배로 준다고 밝혔다.

### 출처

[Cursor 가격 페이지, 10월 13일 확인](https://cursor.com/en-US/pricing)

### 내 생각

전환 페이지에 Pro+와 비슷한 급이 Super라고 나와 있어서 Pro+에서 Super로 바꿨다. Grok을 많이 쓰고 다른 프로바이더는 이미 따로 구독 중이라, 다른 회사 모델이 빠져도 손해가 없다고 판단했다. Super의 Grok, Composer 사용량이 Pro+보다 높을 거라고 봤다.

## 옮기면 되돌릴 수 없다

```cards

cards:

    label: 되돌릴 수 없음
  - icon: refresh-cw
    label: 일할 환불
  - icon: git-merge
    label: 계정 통합
```

전환은 선택이지만, 한 번 옮기면 되돌릴 수 없다. 옮기면 Cursor가 기존 구독을 취소하고 남은 기간만큼 환불해 준다. Apple App Store 결제는 따로 처리한다. Cursor 계정이 여럿이면 Cursor가 하나로 합친다.

### 출처

[Cursor 도움말, 10월 13일 확인](https://cursor.com/help/the-x-subscription/overview)

### 내 생각

나도 Cursor Pro+에서 전환하면 되돌아올 수 없어서, 관련 뉴스를 보며 신중하게 판단했다. 사용자 입장에서는 Cursor가 대주던 서드파티 모델 보조금이 사라지기 때문이다.

## X Premium 구독자는 어떻게 되나

```cards
logo: x
cards:
  - icon: badge-check
    label: Plus 체크마크
  - icon: star
    label: Premium 이상
    sublabel: X Premium+
  - icon: refresh-cw
    label: 자동 환불
  - icon: cursor
    label: Cursor 연결
```

Plus에는 체크마크와 크리에이터 도구가 들어간다. Premium부터는 X Premium+ 혜택을 전부 준다. 연결한 X 계정에서 내던 Premium은 전환할 때 xAI가 취소한다. 남은 기간은 자동으로 따로 환불해 준다. 단, Google Play로 산 X Premium은 전환 뒤 Google Play에서 직접 해지해야 한다. 유료 Cursor 플랜이 있으면 cursor.com/unify에서 전환을 시작한다. 그래야 Cursor 계정도 같이 묶을 수 있다.

### 출처

[SpaceXSI 문서, 10월 13일 확인](https://docs.x.ai/x-subscription/x-premium)

### 내 생각

통합 플랜으로 넘어간 뒤, Stripe로 따로 구독하던 X Premium은 직접 해지했다.

## HN과 r/cursor 반응

```cards
cards:
  - icon: thumbs-down
    label: 단독 구매 끝
    accent: rose
  - icon: lock
    label: 한 회사 모델
  - icon: calendar
    label: 연간 구독자?
  - icon: arrow-right
    label: 직접 구독
```

- 이제 Cursor만 따로 살 수 없다.
- "Cursor의 전성기는 끝났다."는 댓글이 추천을 가장 많이 받았다.
- 차라리 모델 회사에 직접 구독하겠다.
- Codex나 Claude Code처럼 도구가 한 회사 모델에 묶여 간다.
- 연간 Pro+나 X 구독자는 어떻게 되느냐, 결국 더 비싼 플랜으로 밀어내는 것 아니냐는 불만이 많았다.
- Super에 다른 회사 구독을 더하면 오히려 낫다는 사람도 일부 있었다.

### 내 생각

다른 회사 모델이 빠진 대신 Grok 모델 사용량을 2배로 늘렸다는 트윗을 봤다. Cursor만 구독하던 사람에겐 마이너스, Cursor 구독에 Claude나 GPT 구독을 따로 같이 쓰던 사람에겐 쌤쌤, Grok을 쓰는 사람에겐 좋은 변화다. 제일 중요한 건 Grok 4.8과 Composer 3가 나오는 거다.
