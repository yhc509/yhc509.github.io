## 프로젝트 소개

실시간 데이터를 시각화하는 대시보드 웹 애플리케이션입니다.

### 주요 기능

- 실시간 차트 업데이트
- 다양한 차트 유형 지원
- 데이터 필터링 및 정렬
- CSV 내보내기

### 기술 스택

- React 18
- D3.js
- TypeScript
- Tailwind CSS
