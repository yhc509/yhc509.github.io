## 프로젝트 소개

Next.js 15와 MDX를 활용하여 개발한 개인 블로그 플랫폼입니다.

### 주요 기능

- MDX 기반 포스트 작성
- 계층형 태그 시스템
- 다크/라이트 모드 지원
- SEO 최적화

### 기술 스택

- **프레임워크**: Next.js 15
- **스타일링**: Tailwind CSS v4
- **콘텐츠**: MDX, gray-matter
- **배포**: Vercel

## 개발 과정

프로젝트는 약 2주간 진행되었으며, 사용자 경험을 최우선으로 고려하여 개발했습니다.
