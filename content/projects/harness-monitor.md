하네스를 오래 쓰다 보면 중요한 정보와 설정이 어딘가 폴더에 숨겨져 있는 느낌이 든다. 세션, 메모리, skill, MCP, hook, 토큰 이벤트가 다 로컬 어딘가에 흩어져 있는데, 많은 사람들은 이런 게 있는지도 모를 것 같았다. 그래서 그걸 한 화면에서 계속 볼 수 있게 만들었다.

이름을 `codex-monitor`로 하지 않은 이유가 있다. 집에서는 Codex를 쓰고 회사에서는 Claude Code를 쓰는데, 다음에는 다른 하네스도 같이 붙일 생각이기 때문이다. 지금은 Codex 기준으로 시작한 상태다.

`~/.codex`, `~/.agents`, `token_count` 이벤트를 읽어서 프로젝트, 모델, 날짜 기준으로 다시 묶는다. 토큰 페이지, 세션 페이지, Integrations 페이지로 나눠서 사용량 추세와 대화 기록, 설정 상태를 같이 본다. 공급자별 데이터 계층을 따로 두어서 다른 하네스도 붙일 수 있게 잡았다.

토큰 추세를 보고 있으면 생각보다 감정이 섞인다. 어떤 날은 "꽤 했네" 싶고, 어떤 날은 "이 정도밖에 안 했나" 싶다. 결국 내가 하네스를 얼마나 밀고 있는지 스스로 점검하게 된다.

다음에는 과거 세션 공유, 토큰 사용량 공유, Claude Code 지원을 붙일 생각이다.
